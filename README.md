
# MatchMind AI — MVP

نسخة أولية محلية لإدارة العملاء، رصيد التقارير الدائم، طلبات التحليل، وتسليم تقارير PDF.

## المتطلبات
- Python 3.10+
- pip

## التشغيل
```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
```

اضبط كلمة مرور المدير:
```bash
# macOS/Linux
export MATCHMIND_ADMIN_PASSWORD="ضع-كلمة-مرور-قوية"
# Windows PowerShell
$env:MATCHMIND_ADMIN_PASSWORD="ضع-كلمة-مرور-قوية"
```

ثم:
```bash
streamlit run app.py
```

## ما يعمل الآن
- إنشاء حساب عميل وتسجيل الدخول.
- رصيد تقارير دائم محفوظ في SQLite.
- إضافة الأرصدة يدوياً من لوحة المدير (محاكاة شراء الباقة دون بوابة دفع).
- طلب تقرير لفريق كرة قدم.
- متابعة حالة الطلب.
- رفع PDF من المدير وتسليمه للعميل.
- خصم رصيد واحد فقط عند التسليم الناجح.
- إعادة المحاولة لا تخصم الرصيد مرتين بسبب مرجع فريد لكل تقرير.

## حدود النسخة
- هذه نسخة MVP للتجربة المحلية وليست جاهزة للنشر العام أو لاستقبال بيانات حقيقية حساسة.
- لا يوجد بعد محرك لجلب آخر 10 مباريات أو تحليل الإحصائيات.
- لا يوجد تكامل دفع.
- قبل النشر التجاري يجب إضافة مصادقة إنتاجية، HTTPS، حماية من إساءة الاستخدام، نسخ احتياطي، تخزين ملفات آمن، وسجل تدقيق.
- لا تُستخدم بيانات تجريبية على أنها إحصائيات حقيقية. ربط مزود بيانات مرخص يأتي في المرحلة التالية.
